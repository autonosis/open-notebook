# Speaker voice auditions

Podcasts → Profiles → Create speaker / Edit speaker profile has Preview voice beneath each Voice ID. Voice ID uses an unfiltered native dropdown containing the selected provider's complete voice catalog. Custom voice ID remains available as an optional expandable field. The selected per-speaker TTS override takes precedence over the profile default. A short fixed neutral sentence is synthesized by that configured model; names/backstories/personality are not sent for previews. Kokoro previews are entirely local. Other providers use their configured inference service.

Preview does not submit the profile form. Changing the voice/model removes old audio, cancels outstanding browser requests and revokes blob URLs. The generated sample plays inline and can be replayed using normal audio controls. Browser autoplay policy can require pressing Play. Profile names/personas shape the script; voice ID selects the sound.

Authenticated endpoints: GET /api/podcasts/voices?model_id=... and POST /api/podcasts/voices/preview with model_id/voice_id. The API requires a TTS model, bounds the voice identifier, serializes new preview synthesis and caches successful MP3s under data/voice_previews. Cache keys include model identity/provider/name, voice and fixed sample text. If replacing a model/endpoint behind an unchanged registry ID, clear its preview cache deliberately to avoid stale samples. Files are private atomic writes; failed or empty synthesis does not become a cached sample. No profile or episode is created/modified. Catalog support depends on the provider; custom voice IDs can still be entered.

Validation: production build, targeted Ruff and 26 focused backend tests passed; VoicePreview/EpisodeCard frontend tests passed (6 tests), including three consecutive selection/preview cycles with the complete catalog retained. Browser verification also selected and played af_alloy, af_bella and am_michael consecutively, with all 72 voices still selectable afterward. Actual Kokoro catalog returned 72 IDs. af_heart and am_michael both returned HTTP 200 audio/mpeg with distinct sample files lasting 5.784 and 6.336 seconds. First generation took about 3 seconds each; cached replay took 0.067 seconds. Local Whisper transcribed the complete fixed preview sentence accurately. Browser editor displayed and played the generated sample; no profile was saved. Unauthenticated preview calls return 401. No episode was regenerated or active job interrupted. Private sample evidence remains outside Git.

Voice labels follow Name — Language/accent · Female/Male (for example, Heart — American English · Female). Version and variant tokens remain in the name to distinguish catalog entries; option values and saved voice IDs remain unchanged. Unrecognized IDs retain provider-supplied names.
