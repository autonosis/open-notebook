# Large-document transformations and downstream retry

A 1,388-page book extracted and indexed successfully (3,719,954 characters, 3,677 chunks), but its Dense Summary exceeded the provider's input context. Increasing an output-token ceiling cannot make an oversized input fit.

Transformations above 120,000 characters now process every ordered part, saving intermediate outputs privately under data/transformation_checkpoints. Parts are split at nearby line boundaries without dropping text. Intermediate notes preserve source facts, methods, numerical evidence and qualifications; recursive synthesis reduces them to a bounded final input. No original pages are silently truncated. This is a lossy hierarchical analysis, not a verbatim substitute for the original text; small-document behavior is unchanged. Individual sections can lack context from other sections. Final factual quality still needs source review.

Checkpoint keys cover the entire source text, system instructions, model identifier and staged algorithm revision. Completed stages are reused after an interrupted model request; incomplete or empty outputs are rejected. Non-contracting synthesis fails instead of looping indefinitely. Checkpoints contain private research content, are included in application-data backups and remain until explicitly cleaned while jobs are idle. Changing an endpoint/model behind the same model registry ID requires clearing that transformation cache. Provider requests remain sequential.

Source retry now resumes transformations when both saved full text and an existing index are present, skipping extraction and embedding. Existing transformation titles are skipped on this resume path. This assumes retained source text/index remain valid; importing a changed document requires reprocessing/reindexing it deliberately. A new root job preserves the old failure as history and tracks remaining transformation completion. The status becomes Ready only after requested insights are saved.

Validation: 15 focused unittest tests and 27 existing transformation-output regressions passed; targeted Ruff checks and production image build passed. New coverage includes lossless partition coverage, bounded model inputs, all-part final synthesis, persistent reuse across a simulated interruption, contraction failure and a source resume which never invokes extraction/indexing. Full-book live outcome must be recorded separately after completion.
